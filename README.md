# Petit Pas — тренажёр иностранных языков

Веб-приложение (SPA без зависимостей) для изучения **английского, французского,
японского и сербского** языков с интервальным повторением (SRS), геймификацией
и ежедневными сессиями. Цель — учить несколько языков параллельно и не бросать.

## Запуск

```bash
npm start         # поднимает статику на http://localhost:3000 (npx serve)
```

Сборка не нужна: это чистый ES-modules фронтенд. Любой статический сервер
подойдёт (`python3 -m http.server`, `serve`, GitHub Pages и т.д.).

## Архитектура

```
index.html            точка входа, грузит app/main.js
app/
  main.js             SPA: роутер (#-хэши), все экраны и тренажёры
  store.js            состояние, SRS (Лейтнер + ease), XP/уровни/стрики/ачивки
  audio.js            озвучка через Web Speech API
  style.css           вся вёрстка
data/
  english.json        контент языка (см. формат ниже)
  french.json
  japanese.json
  serbian.json        самый полный курс — эталон наполнения
```

Прогресс хранится в `localStorage` (ключ `petitPas_v2`); экспорт/импорт —
в настройках.

> `english/`, `french/`, `japanese/`, `serbian/` в корне — это **старый
> статический сайт v1**, не связанный с SPA. Кандидат на удаление/миграцию.

## Формат данных языка

```jsonc
{
  "name": "Сербский", "flag": "🇷🇸", "code": "serbian", "speechLang": "sr-RS",
  "conjugationPronouns": ["ја","ти","он/она/оно","ми","ви","они/оне/она"],
  "levels": {
    "beginner": {
      "vocabulary": {
        "nouns":  [{ "front": "човек / čovek", "back": "человек",
                     "frontHint": "м.р.",
                     "example": "Тај човек је мој комшија. — Тот человек мой сосед." }],
        "verbs": [], "adjectives": [], "others": []
      },
      "grammar":  [{ "title": "...", "content": "<p>HTML-урок</p>" }],
      "grammarSections": [{ "title": "Раздел", "from": 0, "to": 4 }],
      "quiz":     [{ "question": "...", "options": ["a","b"], "correct": 1, "explanation": "..." }],
      "exercises":[{ "sentence": "Ја _____ студент.", "answer": ["сам"], "hint": "глагол бити" }],
      "reading":  [{ "title": "...", "text": "...", "translation": "...",
                     "questions": [{ "question": "...", "options": ["..."], "correct": 0 }] }],
      "conjugation":[{ "infinitive": "бити", "tense": "презент",
                       "conjugations": ["сам","си","је","смо","сте","су"] }],
      "declension": [{ "word": "жена", "forms": [{ "caseName": "генитив", "answer": "жене", "hint": "кога/чега" }] }],
      "reorderExercises":  [{ "words": ["Ја","идем","у","школу"], "correct": "Ја идем у школу", "translation": "Я иду в школу" }],
      "matchingExercises": [{ "pairs": [{ "word": "пас", "translation": "собака" }] }],
      "dictationWords":    [{ "text": "добар дан", "translation": "добрый день" }]
    }
  }
}
```

Поля необязательны: экран показывает только те разделы, для которых есть данные.
**Matching, диктант и cloze-упражнения автоматически генерируются из словаря**,
если для уровня нет своих курируемых наборов — поэтому новый язык получает эти
тренажёры сразу, как только в нём появляется vocabulary.

## SRS

Интервалы Лейтнера `[0,1,3,7,14,30]` дней × `ease`-фактор (1.3–3.0). Четыре
кнопки качества: **Снова / Трудно / Хорошо / Легко** (`store.js`). Слово с
большим числом ошибок попадает в режим «Разбор ошибок».
